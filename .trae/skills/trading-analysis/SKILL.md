# 交易分析技能

分析和诊断个人外汇交易数据，发现行为模式和问题，并提供改进建议。

## 触发条件

- 用户要求分析交易数据/复盘
- 用户询问盈亏原因
- 用户希望了解交易模式或行为问题
- 用户需要改进建议

## 核心功能

### 1. 数据读取

从 `gold_trading` 数据库读取交易数据：

```sql
-- 连接参数（从 .env 读取）
DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME

-- 核心表
trades       -- 交易记录（含品种、盈亏、手续费、隔夜费）
capital_flows -- 资金流水（入金、出金、赠金）
```

### 2. 分析指标

| 指标 | SQL 计算方式 | 意义 |
|------|-------------|------|
| 胜率 | `SUM(profit>0)/COUNT(*)` | 判断交易胜率 |
| 盈亏比 | `AVG(盈利)/ABS(AVG(亏损))` | 判断盈亏平衡能力 |
| 品种盈亏 | `GROUP BY symbol` | 哪个品种赚钱/亏钱 |
| 月度趋势 | `GROUP BY DATE_FORMAT(ym)` | 按月查看盈亏变化 |
| 连续亏损 | 按时间顺序扫描 | 最大连续亏损次数 |
| 大额亏损 | `profit+commission+swap_fee < -50` | 单笔大亏分析 |
| 最大回撤 | 累计盈亏曲线峰值到谷底 | 风险控制能力 |
| 阈值突破检测 | 累计净值达到某高点后的行为 | 分析阈值魔咒 |

### 3. 阈值突破检测（重点）

用户反馈存在"阈值魔咒"——每次盈利到达某一阈值（如 1200）后就会直线下跌。

检测方法：

```sql
-- 1. 计算累计净值曲线
-- 2. 扫描所有"新高"点
-- 3. 分析新高后的 20-50 笔交易行为
-- 4. 对比"新高前"和"新高后"的差异：
--    - 手数变化（是否加仓）
--    - 亏损容忍度变化（是否扛单）
--    - 交易频率变化
--    - 品种选择变化
```

### 4. 诊断报告结构

输出格式：

```
=== 交易诊断报告 ===

一、核心指标
  总交易: N | 胜率: XX% | 盈亏比: X.XX | 净盈亏: XXXX
  最大回撤: XXXX | 连续亏损: X 次

二、品种分析
  品种A: 盈利/亏损 XX
  品种B: 盈利/亏损 XX

三、月度趋势
  本月: XX | 上月: XX | 同比: XX

四、行为分析
  - 盈利后手数变化趋势
  - 亏损后手数变化趋势
  - 大额亏损分布

五、阈值检测
  - 历史高点: XXXX
  - 高点后行为差异
  - 阈值突破建议

六、改进建议
  - 基于数据的具体建议
  - 止损/止盈优化方案
  - 仓位管理建议
```

## 自定义策略通道

用户可在 `strategies/` 目录下添加自定义分析策略，实现个性化分析。

### 添加策略

1. 在 `strategies/` 下创建 `my-strategy.md` 文件
2. 按以下格式编写：

```markdown
---
name: "策略名称"
trigger: "触发条件（如：连续亏损3次后）"
---

# 策略说明

## 分析逻辑
描述你的策略思路和判断逻辑

## 执行规则
1. 规则一
2. 规则二
3. 规则三

## 参数
- 参数名: 默认值（说明）

## 示例
[可选] 举例说明策略效果
```

3. 加载 SKILL 后，技能会自动读取 `strategies/` 目录下的所有策略
4. 根据用户选择的策略进行针对性分析

### 策略模板示例

详细模板见 `strategies/README.md`。

## 使用方法

```
加载此技能 → 自动连接数据库 → 拉取交易数据 → 生成诊断报告 → 应用用户自定义策略分析
```

## 注意事项

- 连接数据库需确保 `.env` 配置正确
- 分析基于已有历史数据，不包含实时行情
- 建议定期（每周/每月）运行分析，追踪改进效果
