# 自定义策略通道

在这里添加你自己的想法和交易策略，技能加载时会自动读取并应用。

## 如何添加策略

1. 在 `strategies/` 目录下创建一个 `.md` 文件（如 `my-strategy.md`）
2. 按下面的模板填写内容
3. 加载 `trading-analysis` 技能后，可以选择应用你的策略

## 完整模板

```markdown
---
name: "你的策略名称"
trigger: "什么情况下触发这个策略"
---

## 策略思路

用你自己的话描述这个策略的思路。比如：
"当 XAUUSD 出现 XXX 形态时，我认为应该做多/做空"

## 判断逻辑

1. 第一步：写你的判断条件
2. 第二步：写你的操作规则
3. 第三步：写你的退出规则

## 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 止损 | 5 美元 | 单笔最大亏损 |
| 止盈 | 15 美元 | 单笔目标盈利 |
| 最大手数 | 0.03 | 不得超出 |

## 验证方式

描述如何验证这个策略是否有效。比如：
- 回溯历史数据看胜率
- 对比策略执行前后的盈亏变化
- 模拟交易一段时间

## 备注

[可选] 你的学习心得、观察到的现象、待改进的地方
```

## 示例策略

以下是一个简单的"止损纪律"策略示例，供参考：

### 止损纪律检查策略

```yaml
策略名称: 止损纪律检查
触发条件: 单笔亏损超过净值 2%
```

**检查清单**：
- [ ] 当前仓位是否设置了止损价？
- [ ] 止损价是否在合理范围内（不超过净值 2%）？
- [ ] 是否因为亏损而加仓了？
- [ ] 是否因为连续亏损而改变策略？

## 最佳实践

- 一个文件只写一个策略
- 尽量用数据说话，比如"我观察到亏损超过 10 美元后，有 80% 的概率会继续亏损"
- 定期回顾和更新你的策略
- 标注哪些策略有效、哪些需要改进
